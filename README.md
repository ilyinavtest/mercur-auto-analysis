# Анализ рынка новых автомобилей в Казахстане (2019 г.)

## Описание проекта
Учебный проект по анализу датасета продаж новых автомобилей в Казахстане за 2019 год. Цель работы — очистка данных, исследовательский анализ (EDA), оценка позиций компании **Mercur Auto** на рынке и формирование рекомендаций для бизнеса.

## Структура репозитория
* `mercur_auto_analysis.ipynb` — ноутбук с полным кодом, графиками и выводами.
* `mercur_auto_clean.csv` — очищенный датасет, готовый для дальнейшего анализа.
* `README.md` — описание проекта и ключевые выводы.

## Этапы работы
1. **Загрузка и первичный осмотр данных** — изучение структуры, типов и пропусков.
2. **Очистка данных** — удаление неинформативных столбцов и дубликатов, обработка аномалий (объем двигателя, грузовики, возвраты), унификация категорий (страны, топливо, привод, трансмиссия, компании).
3. **Исследовательский анализ (EDA)** — распределение цен, объемов двигателя, года выпуска; анализ продаж по брендам, регионам, топливу и коробкам передач; проверка связей (корреляция цены и объема) и динамики по месяцам.
4. **Анализ рынка и позиции Mercur Auto** — расчет доли в штуках и деньгах, сравнение среднего чека, определение конкурентов.
5. **Выводы и рекомендации** — сильные/слабые стороны компании, ограничения исследования.

## Ключевые выводы
* **Рынок:** общий объем — 29 977 проданных авто на сумму 653.7 млн USD. Средний чек — 21 806 USD. Лидеры по продажам: Hyundai, Toyota, Lada. Большинство продаж — бензиновые авто (89.9%) с автоматической коробкой (86.7%). Основные регионы: Алматы и Нур-Султан.
* **Mercur Auto:** доля в штуках — 1.25%, в деньгах — 2.25%. Средний чек — 39 129 USD (на 79.4% выше рынка), что указывает на премиальное позиционирование. Портфель брендов: Volkswagen, Porsche, Audi. По Porsche и Audi компания — единственный дилер в данных.
* **Сильные стороны:** премиальное позиционирование, уникальность брендов, высокая доля в деньгах.
* **Слабые стороны:** низкая доля в штуках, узкий портфель брендов, конкуренция в сегменте Volkswagen.
* **Рекомендации:** укреплять премиальное позиционирование, диверсифицировать портфель брендов, развивать Volkswagen в премиум-сегменте, адаптировать маркетинг под сезонность.

## Инструменты
* Python (pandas, numpy, matplotlib, seaborn)
* Jupyter Notebook (Google Colab)

## Ограничения исследования
* Данные представлены только за январь–сентябрь 2019 года (неполный год).
* В датасете нет других дилеров, продающих Porsche и Audi, что может быть особенностью выгрузки, а не реальной рыночной ситуацией.
* Гипотезы о причинах сезонности и влиянии премиального позиционирования требуют дополнительной проверки.
